## 📝 Enunciado del Problema

> **Límites:** `Tiempo máximo: 3,000 sMemoria máxima: 4096 KiB`

Dado el valor de una base x
    (1 ≤ x ≤ 100) y el valor
    de un exponente n
    (0 ≤ n ≤ 1.000.000), se
    trata de realizar el siguiente cálculo:

x0 + x1 + x2 + … + xn


### Entrada

La entrada estará compuesta por distintos casos de prueba. Cada
    uno de ellos aparecerá en una línea independiente que tendrá dos
    números enteros x y n.


### Salida

Para cada caso de prueba se escribirá, en una línea
    independiente, el resultado de evaluar la serie de potencias
    anterior para los valores de x y n dados.

Para evitar problemas de desbordamientos, se escribirá el
	 resultado módulo 1.000.007.


### Entrada de ejemplo

```text
1 2
2 3
3 4
2 19
```


### Salida de ejemplo

```text
3
15
121
48568
```
